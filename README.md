# Webshop

A React webshop built with Vite, fetching real product data from DummyJSON API.

## Features
- Product listing with search and debounce
- Product detail pages
- Shopping cart
- Checkout with order confirmation
- Responsive navbar with category navigation

## Tech Stack
- React
- React Router
- Vite
- DummyJSON API

## How to run
1. Clone the repo
2. Run `npm install`
3. Run `npm run dev`
4. Open `http://localhost:5173`
